# Rockin · Recursos per compondre

Pàgina web per a les bandes de l'aula del programa Rockin: idees, cançons i exemples per fer la seva pròpia música.

- **De què parlem:** temàtiques amb cançons de referència i preguntes per parlar-ne.
- **La base:** rodes d'acords per començar, amb el codi de trasts.
- **La lletra:** de la prosa d'idees a la lletra, i figures retòriques amb exemples.
- **Com comença, a l'escenari i com acaba:** recursos per a l'inici, el directe i el final, amb vídeos d'exemple.

Obre-la a: https://rockin-cat.github.io/recursos-per-compondre/
